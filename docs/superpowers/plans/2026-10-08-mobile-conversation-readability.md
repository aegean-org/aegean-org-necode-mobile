# 手机桌面会话阅读体验优化

## 范围
依据用户已确认的布局示意，优化 Android Desktop Connect 会话页，不改协议、运行状态与发送流程，不打 APK，不提交。保留已有脏工作。

## 实施
1. 在现有 DesktopProject / DesktopSession 上增加显示名称，测试 Windows / Unix 路径、服务端默认标题和自定义标题。
2. 收紧会话顶部，显示电脑与项目完整语义；刷新移到会话菜单，浏览页保持原入口。模型选择与错误恢复移到输入框上方。
3. 阅读字体作为未设置用户的默认；不覆盖已保存偏好。Markdown 代码字体独立于正文，桌面会话启用适量行间距，收敛标题字号、列表圆点和横向缩进，保留原段落结构。
4. 运行必要的显示规则单测、Kotlin 编译和改动差异检查，确认 APK 未变化。无打包/安装，不声称已通过真机验收。
